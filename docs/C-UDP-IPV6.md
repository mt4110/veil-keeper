# C の UDP / IPv6 検証結果と再現課題

2026-11-23 に、NIC のない aarch64 QEMU guest（Linux 6.12.112、nftables 1.1.7） で Rust 版を実行しました。C は IPv4/IPv6 の TCP、未接続 UDP、接続済み UDP の6グループで各11試行を完了しました。各グループで対象 slice の許可と拒否、拒否前後の受信器の疎通、解除後の復帰、誤 slice の対照を照合し、最後にルールセットが初期状態へ戻ったことを確認しました。B の42フェーズも同じ隔離条件で照合しました。

旧実装は IPv4 TCP の条件を満たした後、未 bind UDP の送信側が未指定アドレスを返し、受信側の loopback と一致せず停止しました。Rust 版では UDP の送信元を loopback へ明示 bind し、送信側と受信側のアドレスとポートの照合を維持しています。
